# Bienvenido a nuestro Miniproyecto Sección 4

Autores: María Clara Ávila Chinchia, David Alejandro Ibáñez Barrios y Mateo José Giraldo Castillo

En este proyecto se realizó mediante el conjunto de datos clínicos prporcionado el estudio de enfermedades cardíacas. Se incluyó la revisión y tratamiento de valores nulos, la exploración de distribuciones univariadas de variables numéricas y categóricas, y el análisis de relaciones entre estas variables y el target.

También se aplicaron técnicas gráficas como histogramas, diagramas de cajas, gráficos de barras agrupadas, test de normalidad y curvas ROC, lo que permitió identificar tendencias, posibles valores atípicos y diferencias significativas entre pacientes con y sin diagnóstico de enfermedad cardíaca.

Este trabajo constituye una base sólida para el desarrollo de modelos predictivos que busquen clasificar el riesgo de enfermedad cardiovascular y aportar herramientas de apoyo en la práctica médica.
